# 🧑‍🏫 Целевая аудитория
Ученики 5–9 классов: получают мгновенную обратную связь за активность.
Учителя: получают инструмент мягкой мотивации без ручного ведения журналов.

# 🔥 Проблема

85% школьников теряют внутреннюю мотивацию к 8 классу (данные РНФ, 2022). Оценки и замечания не работают на вовлечение, а ручное начисление баллов в других сервисах отнимает у учителя 10–15 минут в день.

# 💡 Решение

Внутренняя экономика класса на базе мессенджера MAX. Учитель начисляет баллы за прилежание и помощь, ученики тратят их в «Магазине привилегий» или переводят в «Общий котёл» класса.

# 🛠 Как это работает

Для ученика:

Заходит в бот → видит баланс и статус (Новичок → Легенда).
Открывает «Магазин» → выбирает привилегию (например, «+1 день к дедлайну» за 10 баллов).
Нажимает «Купить» → баллы списываются, учителю приходит уведомление.

Для учителя:

Открывает админ-панель.
Выбирает ученика и нажимает «+5» за помощь на уроке.
Баланс обновляется мгновенно, история сохраняется в JSON.

Учитель может добавлять и удалять учеников через бота («Управление учениками»). При добавлении бот генерирует уникальный 4-значный код — передайте его ученику для первого входа.
# 🏪 Магазин привилегий
Малые (5–15 б.): Ответить с места, выбрать музыку на перемене.
Средние (20–50 б.): +1 день к дедлайну, провести фрагмент урока.
Большие (60–150 б.): Стать наставником для младших, выбрать тему классного часа.
Общий котёл (500–1500 б.): Кино вместо урока, чаепитие, экскурсия.
# 🐳 Техническая реализация
Язык: Python 3.11
Фреймворк: maxapi
Хранение данных: Легковесные JSON-файлы (schools/school_1/...). Не требует базы данных, работает из коробки.
Деплой: Docker-контейнер.

# 🐳 Сборка Docker-образа (Инструкция для жюри)

Проект упакован в легковесный Docker-контейнер. Для запуска бота не требуется установка зависимостей на хост-систему.

Убедитесь, что на машине установлен Docker.

Склонируйте репозиторий и положите файл token.max с токеном из MAX в корень проекта.

ℹ️ Файл token.max не хранится в репозитории (добавлен в .gitignore) — его нужно создать самостоятельно.

Выполните сборку образа из корня репозитория:

   ```bash
   docker build -t spectrball-bot .
   ```
Запустите контейнер:
   ```bash
docker run -d --name spectrball --restart unless-stopped \
  -v $(pwd)/schools:/app/schools \
  -v $(pwd)/token.max:/app/token.max \
  spectrball-bot
   ```
## Запуск без Docker (через командную строку)

1. Установите Python 3.11+.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `token.max` с токеном бота в корне проекта.
4. Запустите:
   ```bash
   python main.py
   ```

# 🛡 Защита от накруток
Лимит передачи баллов: не более 30% от личного баланса в неделю.
Привилегии покупаются только за свой баланс.
Все транзакции логируются в JSON.
